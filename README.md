# 职场风险管理系统 (Workplace Risk Simulator) 🚀

这是一个基于 **敏感性分析 (Sensitivity Analysis)** 的决策模型工具，旨在通过硬核数据建模，量化线上会议中“被点名/划水失败”的潜在风险。

### 🌟 项目核心价值
在复杂的职场环境中，个人注意力的分配本质上是一个风险博弈问题。本项目将研究生阶段的敏感性分析理论下沉至日常办公场景，为职场人提供科学的“划水”决策依据。

### 🧠 建模逻辑与公式
本项目采用多变量回归思路，定义安全指数 $S$：
- **核心公式**：$S = (1 - \frac{B}{N}) \times D$
- **变量说明**：
  - $N$ (Numbers)：参会人数。人数越多，个体暴露概率越低（风险稀释）。
  - $B$ (Boss Factor)：老板兴奋度。与点名频率成正比。
  - $D$ (Defense)：废话防御力。受会议硬核度与行业背景（如金融/互联网）的系数修正。

### 🛠️ 功能亮点
- **实时敏感性曲线**：可视化边际安全感随人数变化的斜率，识别“风险临界点”。
- **风险热力图 (Heatmap)**：二维坐标展示“人数 vs 硬核度”的交叉影响，直观识别安全天堂与高危区。
- **动态模拟**：集成“黑天鹅”随机事件（如老板接电话、网络掉线），模拟真实的动态波动。
- **行业预设**：针对互联网、金融审计、体制内等不同场景进行权重参数预设。

### 💻 技术栈
- **Visualization**: Chart.js
- **Logic**: Vanilla JavaScript
- **UI**: CSS3 Flexbox & Grid (Dark Mode optimized)
